# Simple Calculator (Go Version)

A command-line calculator application written in Go, migrated from Java.

## Features
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Modulo operation
- Clear total functionality
- Interactive command-line interface

## Building
```bash
go build -o calculator cmd/main.go
```

## Running
```bash
./calculator
```

## Testing
```bash
go test
```
